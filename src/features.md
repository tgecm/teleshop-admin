# Teleshop — Complete Feature Overview

> Marketing-friendly. No sensitive/internal details.

---

## Platform Overview

Teleshop is a **multi-platform e-commerce management system** that lets you create, manage, and grow an online store through Telegram, a dedicated website, and more — all from one dashboard.

---

## 1. Dashboard & Analytics

### Real-Time Performance Metrics
- **Revenue tracking** — Total, daily, monthly, and custom date ranges
- **Order stats** — Total orders, pending orders, items sold, products sold
- **Customer metrics** — Total users, new sign-ups over time

### Interactive Charts
- Area, Bar, Line, and Pie chart views
- Toggle between Revenue, Orders, and Users data
- Date presets: 7d / 30d / 90d / 365d + custom date picker

### Top Products Panel
- Ranked product list by revenue
- Percentage share and order counts
- Visual progress bars

### CSV Export
- Export orders, daily summaries, top products, customers, and stats
- Custom date range and status filters
- Choose which sections to include

---

## 2. Order Management

### Complete Order Lifecycle
- View orders from Telegram, Website, and Guest checkout in one place
- Search by customer name, order ID, invoice, receipt
- **Status pipeline**: Pending → Confirmed → Processing → Shipped → Delivered
- Quick status updates with one click

### Payment Verification
- View submitted payment proof images
- Confirm or reject payments
- Buyers are auto-notified on status change

### Invoice & Receipt Downloads
- Generate professional invoices and receipts as images
- Includes bot logo, customer info, item details, and amounts

---

## 3. Product Management

### Product Catalog
- Add, edit, and delete products
- **Multiple images** per product (up to 10, auto-compressed)
- **Categories** — Organize products, create categories on the fly
- **Stock control** — Unlimited, out-of-stock, or custom quantity

### Pricing & Promotions
- Regular price + optional **promotional price**
- Original price displayed with strikethrough
- Validation ensures promo price doesn't exceed original

### Product Variants
- **Color variants** — Predefined color palette with optional per-color images
- **Custom options** — e.g. Size, Material — with multiple values each (up to 10 option groups)

### Product Sorting
- Drag-and-drop to reorder products
- Filter by category

### Coupon System
- Create discount coupons (Fixed MMK or Percentage)
- Set usage limits, expiry dates, and minimum spend
- Auto-generated coupon codes
- Coupon manager with usage statistics

---

## 4. Customer Management

### Unified Customer View
- **Telegram customers** — From bot interactions
- **Website customers** — From ecommerce sign-ups
- Search by name, username, or ID

### Customer Profiles
- View contact details (phone, email, address)
- Order history per customer
- Join date

### Access Control
- Block or unblock customers

## 5. Payment Methods

### Flexible Payment Setup
- Add multiple payment methods (wallet, bank transfer, etc.)
- Bank/wallet name, account name, phone number
- Optional notes for customers

### QR Code Support
- Upload QR codes for each payment method
- Auto-compression on upload

### Toggle Active/Inactive
- Enable or disable payment methods anytime

## 6. Chat & Customer Support

### Multi-Source Inbox
- Messages from Telegram, Signed-in Website users, and Guest visitors
- Unread count badges per channel

### Rich Messaging
- Send and receive text, photos, audio, voice messages, videos, stickers, and documents
- Inline audio player for voice messages
- "Open in Telegram" links for media

### Smart Features
- **Mark as Read / Unread** per conversation
- **Delete chat** with confirmation
- **Long-press to copy** message text on mobile
- Auto-refresh for new messages

### AI Agent Integration
- Toggle AI assistant on/off per website visitor
- AI handles common customer queries automatically

## 7. Broadcast & Engagement

### Mass Broadcast
- Send messages to all bot users

## 8. Telegram Bot Customization

### Bot Captions
- Edit 9 different bot screen messages:
  - Welcome, Shopping, Search, View Cart, My Orders
  - Settings, Support, About, Order Confirmation

### Bot Posters
- Upload custom images for 11 bot menu screens:
  - Main Menu, Shopping, Search, View Cart, My Orders

### Custom Commands
- Create text-based Telegram commands (e.g. `/help`, `/hours`)

## 9. E-commerce Website

### Public Shop Page
- Your own ecommerce store at `telegramecommerce.shop/{your-shop}`
- **Custom domains** — Use your own domain (e.g. `shop.yourbrand.com`)
- Step-by-step DNS setup guide

### Shopping Experience
- Product browsing with category filters and search
- Image galleries with touch/swipe navigation
- Color and variant selection
- Shopping cart with quantity adjustment

### Coupon Support
- Apply discount codes at checkout
- Validate minimum spend and usage limits

### Checkout Options
- **Signed-in checkout** — via Google or Telegram login
- **Guest checkout** — No account required
- Multiple payment methods to choose from

### Customer Dashboard
- Order history and status tracking
- Download invoices and receipts
- Profile management

### Shop Themes
- Multiple color themes to match your brand
- Choose and apply with one click

### Shop Banners
- Upload up to 5 banner images (1200×400)
- Add clickable links to each banner
- Reorder banners

### Shop Bio
- Short bio text displayed on your shop page

### Order Button Customization
- Choose button label: Order Now, Shop Now, Buy Now, Enroll Now, Book Now, Get Now, Grab Now

## Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS 4, Vite
- **State**: Zustand, React Query, Context API
- **Charts**: Recharts
- **Animations**: Motion (Framer Motion)
- **Icons**: Lucide React
- **Auth**: Firebase + Custom JWT
- **PWA**: vite-plugin-pwa
- **Payments**: MMQR (Myan Myan Pay)
- **Date Handling**: date-fns
